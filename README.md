## 🌎 Project Overview
The Habitat Rowan website was completely rebuilt to modernize the online experience for the organization and the community it serves.  
Our goal was to create a **fast, accessible, and visually engaging site** that makes it easier for users to **donate, volunteer, and learn about Habitat’s impact** in Rowan County.

This project was completed as a **nonprofit service initiative**, developed between **August and October 2025**.

## 🧱 Tech Stack
- **Frontend:** React + TypeScript  
- **Styling:** Tailwind CSS  
- **Deployment:** Vercel + Cloudflare DNS  
- **Content:** JSON-driven content architecture for staff, history, and updates  
- **Integrations:** PayPal Donations, Volunteer Sign-up Flow, Google Workspace, and eBay GivingWorks  

## 🎨 Design & Branding
The visual system was built around **Habitat Blue (#0072CE)** and **Habitat Green (#78BE20)**, following Habitat for Humanity’s brand standards.  
The site incorporates:
- Gradient headers and soft-glass UI backgrounds  
- Responsive layouts for mobile, tablet, and desktop  
- Consistent iconography and modern typography  
- Accessibility-focused color contrast and ARIA labeling
